# 抄底红线监测器

把星球「Coming 星主」2026-10-15 那篇《12 个数据指标 + 红线阈值》里的规则，做成一个本地运行的监控提醒网站。

打开网页就能看到 12 条红线各自触发了没有、离触发还差多少、什么时候该动手、仓位该给多少；新触发红线时会弹桌面通知并响铃。

同一套前端支持**两种运行模式**：

| 模式 | 启动方式 | 谁能改 | 数据刷新 |
|------|----------|--------|----------|
| **本地服务**（功能完整） | `node server.mjs` → http://127.0.0.1:8787 | 只有你 | 盘中每 2 分钟自动抓 |
| **云端只读**（分享给别人） | `node scripts/snapshot.mjs` → 把 `dist/` 托管到 Netlify / GitHub Pages | 谁都不能 | 由云端定时任务重建 |

想把网站分享给别人看，见 **[部署到云端.md](部署到云端.md)**（含一条完全不需要安装 Git 的路线）。

> 规则原文见 [12个数据指标_原文提取.txt](12个数据指标_原文提取.txt)。本工具只做数据聚合与阈值提示，**不构成任何投资建议**。

## 快速开始

需要本机装有 **Node.js 18 或更高版本**（无需 `npm install`，整个项目零第三方依赖）。

```powershell
cd E:\抄底监测器
node server.mjs
```

然后浏览器打开 **http://127.0.0.1:8787** 。

Windows 上也可以直接双击 **`启动监测器.bat`**，它会自动起服务并打开浏览器。

命令行只想刷新一次看看结果：

```powershell
node server.mjs --once
```

服务启动后会自动抓取数据：**盘中每 2 分钟一次，非交易时段每 10 分钟一次**（间隔可在网页设置里改）。
关闭窗口或按 `Ctrl+C` 即停止。

### 生成可以分享的静态站点

```powershell
node scripts\snapshot.mjs          # 抓一次数据，输出到 dist/
node scripts\preview-dist.mjs      # 本地预览 http://127.0.0.1:8899
```

`dist/` 是纯静态文件（只有一个 `data/state.json` 存数据），拖到 Netlify 或推到 GitHub Pages 就能给别人看，
且**天然只读**——没有后端、没有任何写接口，页面上的设置按钮会自动隐藏。

详细部署步骤（包括不需要安装 Git 的路线）见 **[部署到云端.md](部署到云端.md)**。

## 12 个指标的判定口径

| # | 指标 | 红线 | 数据来源 | 自动 |
|---|------|------|----------|:----:|
| 1 | 中证1000 VIX | ≥ 35 | 中金所 MO 期权链**自算**（见下方说明） | ✅ |
| 2 | 融资余额 | ≤ 2.45 万亿（空仓修正位 2.48） | 东方财富 数据中心 | ✅ |
| 3 | IM 贴水 | ≥ 160 点 | 中证1000 现货 − IM 主力合约 | ✅ |
| 4 | 大阴线 | ≥ 3 根，且最大的一根不是第一根 | 中证1000 日K线 | ✅ |
| 5 | 成交量 缩+放 | 缩量若干天后出现「大跌 + 放量」 | 中证1000 日K线（量价） | ✅ |
| 6 | 大盘小盘比 MAX | 创样本区间新高 | 巨潮大盘 / 巨潮小盘（比值自算） | ✅（已按原文锁定为触发） |
| 7 | 6月4次加息率提升 | 默认红线（需跟踪） | 手动 | — |
| 8 | IM 6600 | IM 主力 ≤ 6600 | 东方财富 行情 | ✅ |
| 9 | 科创50 1250 | ≤ 1250 | 东方财富 行情 | ✅ |
| 10 | 韭圈情绪指数 | < 3（等于 3 且补偿 > 10 也算触发） | 手动录入 | — |
| 11 | PCR 3/4 | 4 个品种中 ≥ 3 个低估 | 期权链自算 | ✅ |
| 12 | 6大科技点位 | 主观判断（CPO / 半导体） | 手动 | — |

**评分与建议**：红线数量 → 评分（0–100）→ 等级

| 红线数 | 等级 | 建议 |
|:---:|------|------|
| 0–2 | 等待区 | 机会还没到，空仓等待 |
| 3–5 | 观察区 | 太早动手会在底部扛不住，只做观察 |
| 6–8 | 底仓区 | 无仓位者可买底仓；有仓位可再憋一下 |
| 9–10 | 动手区 | 正式动手，仓位 50%~70%（原文作者本次计划 9 根动手） |
| 11–12 | 重仓区 | 底部特征充分，可上较大仓位 |

## 关于数据源，有几件事要如实说明

1. **中证1000 VIX 是自算的，不是官方 QVIX 值。**
   原文用的「中证1000VIX」通常取自期权论坛的 QVIX 指数导出表（`1.optbbs.com/d/csv/d/k.csv`）。
   该表的「中证1000股指」列自 2026 年起 Excel 公式损坏（全是 `#NAME?`），**最后有效值停在 2026-05-29**；
   同一张表里还有两组列（第 67~78 列）存在两个品种两两交错的数据污染。
   因此这里改用**中金所 MO（中证1000股指期权）实时期权链**，按 CBOE VIX 的方差互换口径自行复算，
   自动选取剩余期限最接近 30 天的合约（当前为 MO2611）。计算明细在指标卡片里可见。
   自算值与官方 QVIX 会有细微差异，**阈值 35 建议按自己的口径微调**，也可以在「手动数值」里直接录固定值。

2. **PCR 的「低估」具体数值，原文没给。**
   原文只写「3 个到达低估之下默认触发」，并让读者自己上投资观察网查。
   这里默认取 **成交量 PCR ≤ 0.85 记为一个品种低估**，4 个品种里 ≥ 3 个即触发。
   这是个**可校准的默认值**，不是原文数据，请在设置里按自己的口径改。
   四个品种：沪深300（中金所 IO）、中证1000（中金所 MO）、中证500（上交所 500ETF 期权）、
   科创50（上交所 科创50 + 科创板50 ETF 期权，两个品种合并）。

3. **东财期权链偶尔会被限流。**
   `push2.eastmoney.com` 的 clist 接口在频繁请求后会拒绝连接。
   程序会自动切到备用主机 `push2test.eastmoney.com`（数据一致），并把期权链缓存 10 分钟。
   万一两个主机都不可用，PCR 会退到**新浪的持仓量口径**（只覆盖沪深300、中证1000 两个品种），
   此时卡片上会明确标出「当前用的是持仓量口径」，因为它和成交量口径的阈值不可直接比较。

4. **有两个指标必须手动维护**，因为原始数据源不公开：
   - **韭圈情绪指数** —— 韭圈儿 App 自研数据，无公开接口，请在网页上录入数值。
   - **6月4次加息率提升 / 6大科技点位** —— 前者原文本身标注「需跟踪，可能回落要去掉红线」，后者原文说「没办法给数据」，都用手动开关。

5. **大盘小盘比 MAX 的定义原文没写死。**
   程序默认用「巨潮大盘 ÷ 巨潮小盘」并计算其历史分位；原文说该指标「前几天已经触发，触发即始终有效」，
   所以默认**锁定为已触发**，卡片里同时展示计算出的参考比值与距历史最高的距离。
   比值对可以在设置里改（支持沪深300/中证2000、上证50/中证1000）。

6. **历史数据是自己攒的。**
   东财 clist 只有实时快照，没有历史 PCR；所有历史都来自本程序逐次刷新时的记录，
   存在 `data/snapshots.json`（每 10 分钟一个点，最多 5000 个）。第一次跑只有一个点，属正常。

## 设置项说明

在网页「阈值与手动维护」面板里可以改，**保存后立即用当前数据重算**，不用等下一次刷新：

- **红线阈值** —— 11 个可调数值（含融资余额空仓修正位、情绪补偿阈值、PCR 低估线与触发个数）
- **算法参数** —— 大阴线的观察窗口与跌幅口径（涨跌幅 / 实体跌幅）、成交量的均线周期与缩放倍数、大盘小盘比的判定比例
- **手动指标** —— 三个开关
- **手动数值** —— 中证1000 VIX、韭圈情绪指数、情绪补偿值；**留空即恢复自动计算**
- **PCR 手动修正** —— 四个品种留空用自动值，也可直接填投资观察网上的数
- **刷新与提醒** —— 盘中刷新间隔、桌面通知、声音开关

配置存在 `data/config.json`，点「恢复默认」可重置。

## 常见问题

**Q：页面显示「无法连接本地服务」？**
服务没在跑。重新执行 `node server.mjs` 或双击 `启动监测器.bat`。

**Q：端口 8787 被占用？**
换一个端口：`$env:PORT=9000; node server.mjs`，然后访问 http://127.0.0.1:9000 。

**Q：某个指标显示「无数据」？**
看页面最下方「数据源状态」，哪一项标红就是它挂了。东财期权链被限流是最常见的情况，等下一轮刷新通常会自动切主机恢复。

**Q：桌面通知没弹出来？**
浏览器要求先授权，且 `file://` 打开的页面不行——必须通过 http://127.0.0.1:8787 访问。若之前点过「阻止」，需在浏览器地址栏的站点设置里重新允许通知。
